| 8 | ② 触发时 | 正文控制在 5k Token 以内 | SKILL.md 文档 + 拆出的两份文件 | 五千→上限标注；拆到→文件弹出；需要时→连线 |
| 9 | ③ 用到时 | 用到时，才去读附件 | 四行文件状态表（原图 05 的界面化） | 其他文件→列表；真用到了→翻一下；不用填表→划掉不读 |
| 10 | ③ 用到时 | 脚本只回传结果 | 代码编辑器 + 终端 + 上下文 | 直接运行→终端打字；代码本身→打叉；只有结果→结果进上下文；校验通过/报错 |
| 11 | ③ 用到时 | 带再多也不占地方，但别乱装 | 原图 05 + 0 Token + 来路不明文件夹 | 很多资料→圈出；不占地方→0；来路不明→问号文件夹；别随便装→手写提醒 |
| 12 | 写的时候 | 描述没写好，Skill 就用不上 | description 一行 + Agent + 睡着的文件夹 | 描述最关键→框住；只靠它→箭头；躺在→文件夹 zzz |
| 13 | 写的时候 | 能做什么、什么时候用，都写上 | 两张对比卡 + 命中率条 | 太短了→打叉；提取文字/填表/合并文件/什么时候该用→逐段出现；机会→长条 |
