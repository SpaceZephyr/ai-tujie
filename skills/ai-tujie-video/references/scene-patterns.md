# 画面：组件、动画、场景写法

## 版面（3:4，1080×1440）

| 区域 | 位置 | 内容 |
|---|---|---|
| 角标 | left 80, top 74 | `.tag`：橙色手写，可带编号圆圈（第几种） |
| 大标题 | top 136，60px 粗体 | 一句人话，各场句式不同 |

## 场景函数

```js
function s6(c) {                       // c 是这一场的时间工具
  const shot = c.at("截一张图");        // 旁白念到「截一张图」的绝对秒数（稿子里要有这几个字）
  return head(c, 3, "截图", "截一张现有页面，在上面改") + `<div class="stage">
    ${box(60, 20, 960, 620, browser("shop.example.com", 页面HTML), A({ at: c.t(.3), fx: "up" }))}
    ${sk(R.rect(70, 82, 940, 70, { color: BLUE, w: 4 }), A({ at: c.at("加个筛选") + .4, fx: "draw", d: .5, out: c.at("换个布局") }))}
    ${hand(70, 780, "加个筛选", A({ at: c.at("加个筛选", .3), fx: "wipe", cls: "b" }))}
  </div>`;
}
```

- `c.t(秒)`：相对本场开头的时间；`c.at("词", 偏移)`：念到这个词的时间（有 align.json 时是真实时间）。
- `c.vs / c.ve / c.end`：本场旁白开始、结束、场景结束。

## 动画属性 `A({...})`

| 参数 | 含义 |
|---|---|
| `at` | 开始时间（绝对秒） |
| `fx` | `draw` 线稿一笔笔画出；`up` 上浮淡入；`fade` 淡入；`pop` 弹出；`wipe` 从左往右擦出（手写字用）；`type` 打字（配 `data-text`）；`count` 数字滚动（配 `data-count="8,24"`）；`ripple` 点击波纹；`none` 到点直接出现 |
| `d` | 动画时长（默认 draw .9 / up .55 / wipe .7 / type 1.2） |
| `out` | 到这个时间淡出 |
| `kf` | 关键帧 `[[t, {x, y, s, r, o}], ...]`：位移、缩放、旋转、透明度，用来拖动光标、飞入、切状态 |
| `cls` | 额外 class，如 `"b"` 橙色手写、`"s"` 灰色小字、`"l"` 大号手写、`"tag"` |

**注意**：A() 自己带 `class` 属性，元素上不要再写 `class="..."`（会被浏览器忽略），用 `cls` 传。父元素的 `at` 也会控制子元素可见性，切状态的父层用 `at: 0`。

## 组件（`engine/lib.mjs`）

- 手绘线稿 `R`：`rect` `fillRect`（橙色实心块）`ell`（圈出重点）`line` `curve` `poly` `arrow`（弯箭头，传 2–3 个点）`check`（打勾）`cross`（打叉）。都返回 path 串，用 `sk(串, A(...))` 包成一层，`fx: "draw"` 按顺序画出。
- 线稿图标 `ICON.xxx(cx, cy, 大小)`：bulb 想法、sketch 草图、crop 截图、globe 网址、code 代码、doc 文档、pen 设计工具、image 图片、clock 时间、cloud 云、folder 文件夹、lock 锁、hand 手。
- `hand(x, y, 文字, A)`：手写字（Hannotate SC）。
- `box(x, y, w, h, 内部HTML, A, 样式)`：放任何真实界面。
- 真实界面外壳：`phone(内部HTML, 样式)` 手机；`browser(网址, 内部HTML, 样式)` 浏览器窗口；代码编辑器、文档、设计工具直接用 HTML + `.mono`/`.u-*` 样式写（见例子）。
- 原文配图 `shot(src, w, h, { fit, pos })`：带阴影的圆角截图卡片；`h` 不给就按原比例。产品图标 `appIcon(src, s, { clip, badge })`：白色圆角方块，`badge` 放公司小图标。
- `cursor(A)` 光标（配 kf 移动）；`tap(x, y, at)` 点击波纹。
- 颜色只用 `INK`（黑）和 `BLUE`（强调色，本 skill 里已改成系列橙 #EE6A1F）。真实界面里的配图用低饱和色块（#F3D6C9、#D9DCEF 这类）。

## 现成写法（`examples/16-Skill运行原理/scenes.mjs`，16 场）

图组类内容的常用画面：时序/流程讲解用「窗口 + 逐行出现 + 框选」，数字用「进度条/大号数字」，对比用「两张卡 + 打叉打勾」，概念区分用「三栏卡」，收尾用「七张原图扇形 + 仓库地址 + 下一篇」。

## 用原图的写法

- 原图用 `shot(IMG(n), 宽)` 放成卡片，一场最多一张，旁边配手写标注说重点（如 s2 放第 1 页时序图、s11 放第 5 页）。
- 原图里的列表、对比、代码，更适合用真实界面重新画一遍，让它跟着旁白一条条出现（如 s9 把第 5 页的文件清单做成状态表）。
- 收尾把 7 张原图扇形排开，带出仓库地址和下一篇。

## 自检

- `render.mjs --stills ends` 看每场结尾：元素都出完了吗？最后一个动作在场景结束前 0.5 秒已完成。
- `--stills mid` 看中段：同一时刻画面上有没有空场超过 2 秒。
- 重叠：手写字之间留够宽度（中文 38px 一个字），标签别压在手机或窗口上。
- 一场画面只有一种橙；不出现 emoji。
