# 踩过的坑

做「16 · Skill 怎么运行」时遇到的问题和处理办法。

| 问题 | 现象 | 处理 |
|---|---|---|
| 句间、场间空白太长 | 用户要求任何无声段 ≤ 0.5 秒 | `tighten.py` 去首尾静音、句内长停压到 0.35 秒；config `lead .15` / `tail .2`；build 后跑 `gaps.py` 验证 |
| 节奏变快后动画来不及出 | 结尾帧里手写字只出一半、卡片没出 | `--stills ends` 逐场看，把 `c.at(最后一个词) + 1` 这类动作挪到前面的关键词上 |
| 语速太慢 | 用户嫌慢 | edge-tts `rate` 设 +15%（不要用 atempo 二次变速，音质会变） |
| edge-tts 偶尔只出半句 | 某句只有 0.3 秒 | `tts.sh` 按字数校验时长，自动重试 3 次 |
| 某些音色吞字 | 云希把「这一次」念成「这次」 | 改稿换说法；`finalize.py` 报「拼音对不上」时先单独截那段再识别 |
| Whisper 把英文听错 | Skill → Scale / Steel / Spill，AI → AEA | 识别问题，不用重配；单独截那几秒再识别确认 |
| 一个元素写了两个 class | 气泡跑到左上角 | 用 `A({ ..., cls: "bubble me" })`，元素上不要再写 `class=` |
| grid 容器里的文字断行 | 「装得再多……」和橙色 span 各占一行 | `display:grid` 的直接子节点会分成多个格子，文字外面再包一层 `<div>` |
| 标题两行压到舞台 | 60px 标题超过一行 | 标题控制在 16 个字以内 |
| 配乐太吵 | 盖过人声 | 配乐 -32 LUFS（比人声低约 15 dB）+ 侧链压低；嫌大就改 config `bgmLUFS` 到 -36 |
| 成片被截短 | 封面附加流和 `-shortest` 在同一条 ffmpeg 命令里 | `mix_bgm.sh` 先合音画，再单独嵌封面 |
| loudnorm 报 TP 越界 | `TP=-12` out of range | TP 只能 -9 到 0 |
| 场景函数里 `c.at` 找不到词 | build 报「稿子里找不到」 | 改稿后同步改 scenes.mjs 里的关键词；关键词取稿子里第一次出现的位置 |
