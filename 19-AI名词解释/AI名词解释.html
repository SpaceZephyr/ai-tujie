AI 原理图解 1901 / 07
第 1 段

发过去的，它才看得见

模型不会自己去翻资料。这一次它能看到什么，全靠我们连着问题一起发过去。发进去的东西，决定了它能答成什么样。

一般发四样：产品的设定和规矩、之前聊过的内容、从资料库里搜到的片段、还有刚打的这句话。四样一起打包，装进一个有上限的盒子。

这四样东西各有各的名字，也各有各的坑：

提示词：这一次发过去的全部文字，更像一份需求说明。写得越具体答得越准，没写清的地方它会自己猜一个
Token：模型不按字数算，按小块算。一个英文单词大概一块，一个汉字一到两块。收多少钱、能装多长、一分钟最多发多少，全按块数
上下文窗口：一次最多装多少块。装满了就自动丢掉最早的那部分，而且它不会告诉你丢了
RAG：先去资料库里搜出相关段落，再连问题一起发给模型。公司知识库基本都是这么做的

这四个里 Token 最常被低估。一份文档到底多少块，得真切一遍才知道，按字数估基本估不准。

AI 原理图解 1902 / 07
第 2 段

它其实只会猜下一个词

东西发进去之后，模型只干一件事：猜下一个词是什么，猜完接上去，再接着猜下一个。一段回答，就是这么几百次攒出来的。

这件事本身就有个名字，叫下一个词预测。它厉害在哪、蠢在哪，基本都能从这一句推出来。至于它有多大本事、知道多少事，在训练的时候就定死了，用的时候改不了。

剩下三个，是真正用的时候会碰到的：

参数量：模型有多大，写成 7B、70B。数字大不等于更聪明，也和能读多长完全没关系
温度：调它答得多保守。调低每次答得差不多，适合干活；调高更发散，适合写文案
推理模型：开口之前先自己想一大段。难题上更准，但想的那一段也要照样收钱

参数量最容易被误会。它说的是模型有多大，不是它一次能读多少字，这是两个毫不相干的数。

AI 原理图解 1903 / 07
第 3 段

它为什么会一本正经地瞎编

它的字是当场编出来的，不是从某个库里查出来的。这一点，是它和搜索引擎最大的区别。

当场编，带来两个后果。不知道的时候，它会拿最像的内容顶上；训练结束之后发生的事，它一概不知道。

它的毛病，基本都能归到这四个词上：

幻觉：不知道就拿最像的顶上，语气和说真话一模一样。这是机制带来的，只能防，等不到修好
知识截止：训练到某个日期就停了，之后的事不知道。问最近的消息，得自己把资料贴给它
多模态：能看图、能听声音的模型。这些本事多半是后加的，小字、表格线、精确位置最容易看错
开源模型：能下载下来自己装的模型。自己装买到的是可控，不是省钱

开源这条最容易误会。公开的一般只有模型本身，训练用的数据和代码通常不给；自己装还得配显卡、自己运维，量不大的时候比直接调接口更贵。

AI 原理图解 1904 / 07
第 4 段

它开始自己动手了

光会说话不够用。把一份工具说明书一起发进去，它就能说出要用哪个工具、怎么用，再由程序去执行，把结果送回来给它接着看。

这样一来一回几十轮，就是所谓的 Agent 循环。每转一圈，前面装进去的东西要重新发一遍、重新算一遍，越滚越长。

这四个词最近到处都在说：

Agent：它不在模型里面，是套在模型外面的一层，管三件事：决定下一步、调工具、卡住哪些事不许做
工具调用：给它一份工具说明书，它说用哪个、怎么用，程序照办。给了什么工具，它就只能干什么
Skill：一包提前写好的做事方法，用到时才调出来，平时不占地方
MCP：一个统一接口，让 Agent 能接上各种外部服务。接一次，到处能用

Agent 又慢又贵，原因就在那个越滚越长上。转二十轮，最早那批内容就被重新算了二十遍。想省钱得从少装点东西下手，换个便宜模型作用不大。

AI 原理图解 1905 / 07
最容易混

这几个最容易搞混

背定义帮不上忙。真正让人栽跟头的是下面这几组，它们听着像一回事。

Token 不按字数算：一个英文单词大概一块，一个生僻汉字可能占到三块。所以按字数估价，估不准
微调教不会新知识：微调是拿一批例子重新训一遍，改的是它说话的口气和格式。想让它知道公司的规章，该用 RAG，不是微调
Agent 不在模型里：它是套在模型外面的一层。同一个模型，外面这层做得好就能干活，做得差就来回绕圈
Skill 和 MCP 不一样：一个装做事的方法，一个装对外的接口。谁也替代不了谁
网页版和接口是两回事：同一个模型，网页版给人聊，接口给程序调。两边的收费方式、能调的参数、聊天记录怎么留，都不一样

第二条最费钱。不少团队花几个月做微调，最后发现搭个检索就解决了。

还有一条容易踩：模型分不清哪句是命令、哪句是资料。它读到的材料里要是藏了一句命令，它可能真的照做，这叫提示注入。

AI 原理图解 1906 / 07
放在一起看

记不住也没关系

上面四段连起来，就是每问一次 AI，它走完的全程。碰到生词，先想它是哪一段的事，比背定义管用。

试一个没讲过的词：蒸馏。它是拿大模型去教小模型，属于训练时候的事，落在模型算那一段的前面。所以它影响的是模型本身的水平，和装进去多少、会不会编，都没关系。

再试一个：限流。它是接口一分钟最多让你发多少块，落在装进去那一段。所以碰到限流，该压的是发过去的量，不是换模型。

四段速查，存下来备用：

1 装进去　提示词 · Token · 上下文窗口 · RAG
2 模型算　下一个词预测 · 参数量 · 温度 · 推理模型
3 吐出来　幻觉 · 知识截止 · 多模态 · 开源模型
4 动手　Agent · 工具调用 · Skill · MCP
